# 🌍 PM3 - Footprinting with Maltego

## ⚠️ Module Note

This module could not be completed in this lab because **Maltego is not available/accessible from Ethiopia** (regional restriction on account creation/activation). 

Maltego requires online account activation (Maltego ID) tied to region based access, which blocked setup in this case.

## What This Module Would Cover
Maltego is an OSINT (Open Source Intelligence) tool used to visually map relationships between domains, email addresses, people, and infrastructure. In this lab, it would have been used to footprint `networkwalks.com` and discover associated email addresses through visual "transforms."
